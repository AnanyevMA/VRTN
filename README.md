# VRTN (VERETENO Workshop)

Репозиторий проекта бренда одежды **VRTN Workshop / VERETENO workshop** (ИП Ананьев Максим Андреевич).

Производство: г. Саяногорск (Республика Хакасия).  
Флагманский шоурум: г. Абакан.  
Официальный сайт: [vrtn.store](https://vrtn.store)

---

## Структура репозитория

* [**`skills/vrtn-letterhead/`**](skills/vrtn-letterhead/README.md) — скилл для генерации официальных писем, обращений, заявлений и претензий на фирменном бланке VRTN Workshop в форматах PDF и DOCX. Включает оригинальный логотип, шрифты Montserrat и автоматический генератор.
* [**`Сайт/`**](Сайт/) — регламенты, правила безопасной работы с Tilda MCP, стратегия SEO и графические материалы сайта.
