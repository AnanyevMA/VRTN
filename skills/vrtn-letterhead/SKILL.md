## 2. Корпоративный стандарт оформления (Brand Identity)

| Элемент | Параметры и правила |
| :--- | :--- |
| **Формат листа** | A4 (210 × 297 мм), книжная ориентация, поля: левое/правое — 16.1 мм (45.7 pt), верх/низ — ~12 мм. Документ должен укладываться ровно в **1 страницу**. |
| **Логотип** | Оригинальный графический знак VRTN Workshop (`assets/logo.png`), ширина 175.75 pt, высота 56.49 pt. Выравнивание по левому краю. |
| **Слоган** | Сразу под логотипом: `VRTN Workshop. С благодарностью за ваш выбор и доверие.` (шрифт Montserrat-Regular 8 pt, цвет `#4a4a4a`). |
| **Разделители** | Тонкие горизонтальные линии (0.5 pt): над блоком реквизитов (цвет `#CCCCCC`), под блоком реквизитов (цвет `#DDDDDD`). |
| **Блок реквизитов** | 2 колонки: слева — реквизиты ИП Ананьев М.А. (7.2 pt), справа — адресат письма (должность, компания, ФИО, адрес, ИНН/КПП, 8.0 pt). |
| **Заголовок** | По центру: вид документа `ЗАЯВЛЕНИЕ` / `ОБРАЩЕНИЕ` / `ПРЕТЕНЗИЯ` (Montserrat-Bold 11 pt) + подзаголовок (Montserrat-Regular 8.5 pt). |
| **Обращение** | `Уважаемый [Имя Отчество]!` (Montserrat-Bold 9.5 pt). |
| **Основной текст** | Шрифт Montserrat-Regular 8.5 pt, интервал (leading) 11.8–12 pt, выравнивание по ширине (justify), цвет `#1a1a1a`. |
| **Выделенный блок (Callout)** | Серая плашка `#F8F8F8` с рамкой `#E0E0E0` для критически важной информации (например, **Причина возврата:** ... или **Предмет запроса:** ...). |
| **Банковские реквизиты** | Таблица с реквизитами для перечисления средств (при возвратах и оплатах). |
| **Подпись** | Слева: `Индивидуальный предприниматель Ананьев М. А.`, справа: линия подписи `_____________________ / М. А. Ананьев /`, `М. П.` и дата `«___» ____________ 2026 г.`. |
| **Подвал (Footer)** | По центру внизу листа: `CREATED IN KHAKASSIA \| EST. 2015 \| VRTN WORKSHOP` (Montserrat-Regular 7 pt, цвет `#777777`). |

## 4. Типовые сценарии использования

1. **Письмо о возврате денежных средств (поставщику / транспортной компании):**
   * Обязательно указывается основание (счет, накладная, УПД, платежное поручение).
   * Сумма цифрами и прописью, выделение НДС.
   * Причина возврата выносится отдельной строкой в рамку (`callout`).
   * Включается таблица банковских реквизитов (`include_bank_details: true`).
2. **Деловое обращение / предложение о сотрудничестве:**
   * Заголовок `ОБРАЩЕНИЕ`.
   * Презентация швейного производства (с 2014 г., г. Саяногорск) и шоурума (г. Абакан).
   * Описание сути запроса (лимиты, топливные карты, поставки тканей, оптовые закупки).
3. **Претензия / Рекламация:**
   * Заголовок `ПРЕТЕНЗИЯ`.
   * Описание факта нарушения (недопоставка, производственный брак полотна, задержка груза).
   * Ссылки на условия договора / ГК РФ.
   * Требования (замена товара, устранение недостатков, возврат денежных средств в срок Х дней).
